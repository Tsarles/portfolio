# Charles Andrew Cabral — Portfolio

A personal portfolio with a hand-drawn notebook style. It presents Charles's background, selected projects, and contact information without losing the playful visual identity of the original site.

## Stack

- React and Vite
- React Router
- GSAP
- Lucide icons
- Vanilla CSS

## Local development

```bash
npm install
npm run dev
```

Before publishing changes:

```bash
npm run lint
npm run build
```
